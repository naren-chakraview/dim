## Quick Start

```bash
# Build
go build -o bin/midctl ./cmd/midctl

# Validate config
./bin/midctl validate route.yaml

# Run pipeline
./bin/midctl run route.yaml

# Send message
curl -X POST http://localhost:8080/ingest \
  -H "Content-Type: application/json" \
  -d '{"amount": 100}'

# Check output
tail -f output/messages.jsonl
```
